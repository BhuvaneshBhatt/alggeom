# Geometric irreducibility and absolute factorization

## Why use this?

A polynomial can be irreducible over `QQ` while defining a reducible variety over an algebraic closure. For example, `x**2 + y**2` is irreducible over `QQ` but has two complex lines as geometric components. A factorization over a rational-function coefficient field does **not** decide this question: `y**2 - x` is irreducible over the algebraic closure of `QQ`, although it factors over an algebraic closure of `QQ(x)`.

`absolute_factor_bivariate` computes geometrically irreducible factors of bivariate polynomials over `QQ`. `absolute_factor_hypersurface` applies the logarithmic-derivative construction to an arbitrary number of affine variables, subject to a linear-system size budget. Both retain multiplicities and construct a common exact number field. Its results feed the principal-ideal path of `absolute_primary_decomposition`. Both routines check exact reconstruction.

```python
import sympy as sp
from alggeom.absolute_factorization import absolute_factor_bivariate
from alggeom.geometric import absolute_primary_decomposition
from alggeom.ideals import PolynomialRing

x, y = sp.symbols("x y")
factorization = absolute_factor_bivariate((x**2 + y**2) ** 2, (x, y))
assert len(factorization.factors) == 2
assert sorted(power for _, power in factorization.factors) == [2, 2]

ring = PolynomialRing((x, y))
primary = absolute_primary_decomposition(ring.ideal((x**2 + y**2) ** 2))
assert len(primary.components) == 2
```

## Exact factorization method

For a squarefree polynomial \(f\in\mathbb Q[x,y]\), solve the exact linear equations for closed rational one-forms \((G\,dx+H\,dy)/f\), with the numerator bidegree bounds \(\deg_x G<\deg_x f\), \(\deg_y G\leq\deg_y f\), \(\deg_x H\leq\deg_x f\), and \(\deg_y H<\deg_y f\). In characteristic zero the dimension of this space equals the number of distinct absolutely irreducible factors. The resulting residue algebra is split by exact multiplication matrices; the characteristic polynomial supplies algebraic residues. Each factor is recovered using an exact polynomial gcd over the resulting number field.

This follows the logarithmic-derivative factorization framework of Gao (2003), built on work by Ruppert (1986). The implementation verifies the polynomial product and, for ideal decomposition, the intersection of primary factors. It does not use numerical approximations to decide irreducibility.

## Nonprincipal complete intersections in disjoint variables

When the generators involve pairwise disjoint blocks of variables, `absolute_primary_decomposition` can combine the certified absolute factors of each generator. For example, the ideal `((x**2+y**2)**2, u**2+v**2)` in `QQ[x,y,u,v]` decomposes into four primary components over `QQ(I)`. Each component is generated by a square of one linear factor in the `(x,y)` block and a linear factor in the `(u,v)` block. The intersection of these components is verified exactly. The proof of primariness uses the fact that products of geometrically integral varieties over an algebraically closed field are integral, and the variables of the defining factors are disjoint. The same path handles more than two blocks and identifies geometrically integral reduced complete intersections with one component. The `max_components` argument bounds the Cartesian product of absolute factors and raises `DecompositionLimitError` if exceeded.

This construction does not apply to coupled polynomial generators that share variables or to arbitrary embedded associated primes. The general engine still raises on such inputs unless another certified method applies.

## Polynomial graphs

`absolute_primary_decomposition` also recognizes positive-dimensional ideals presenting a polynomial graph over affine space. For example, the ideal `(z - x*y, w - x**2)` in `QQ[x,y,z,w]` has coordinate ring `QQ[x,y]`. After checking equality with the graph ideal using exact Gröbner reduction, the algorithm certifies that the ideal remains prime over an algebraic closure. This supports nonprincipal, coupled generators without constructing a splitting field. The criterion is sufficient, not a geometric-primality test for arbitrary ideals.

## Scope and limits

The logarithmic-derivative backend accepts rational-coefficient hypersurfaces in two or more variables. It supports nonhomogeneous, singular, repeated-factor, and reducible examples. Its multivariate construction uses closed logarithmic one-forms in every coordinate, subject to a multidegree coefficient bound. `max_unknowns` bounds the linear system; `max_roots` bounds the residue algebra. If exact algebraic eigenvalues cannot be represented or a budget is exceeded, a `FactorizationLimitError` is raised. The general associated-prime workflow also handles particular nonprincipal positive-dimensional ideals, but **arbitrary geometric primary decomposition of nonprincipal ideals remains unsupported**. Reconstruction of components is necessary but by itself does not certify each associated prime is geometrically prime.
