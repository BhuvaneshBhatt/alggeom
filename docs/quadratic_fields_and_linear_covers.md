# Quadratic constant fields and localized linear covers

Use these interfaces when algebraic constants split a geometric component, or when a parameter quotient has zero divisors and the fiber equations are linear. Each calculation returns exact evidence with an independent verifier. The sections below give the mathematical hypotheses and the scope of their completeness claims.

## Quadratic constant fields

Let `k=QQ`, let `t=(t_1,...,t_r)` be algebraically independent, and let `K=Frac(k[t,y]/(f))` for a prime principal ideal generated by a primitive polynomial `f` of degree two in `y`. Write `f=a y^2+b y+d` over `k(t)`, and let `Delta=b^2-4ad`. The quadratic extension is `k(t)(sqrt(Delta))`.

In characteristic zero, a rational function in `k(t)` is a square in `kbar(t)` precisely when every positive-degree irreducible factor of its numerator and denominator has even valuation: a square over `kbar` must still have even multiplicities, and conversely an even-valuation element is a constant times a rational square, whose constant becomes a square in `kbar`. This criterion can be decided by exact factorization/squarefree factorization. (The implemented code keeps the square class represented by a rational `c` and an exact rational function `s`.)

- If an odd positive-degree valuation occurs, the quadratic remains irreducible over `kbar(t)`. By Gauss's lemma the original hypersurface is geometrically integral, and the full relative constant field is `k`.
- If `Delta=c*s^2` for rational nonsquare `c`, then `sqrt(c)=(2ay+b)/s` in `K` and `K=k(sqrt(c))(t)`. The full constant field is exactly `k(sqrt(c))` because a rational-function field is regular over its coefficient field.

The verifier independently checks the original prime presentation, the square-class obstruction or exact discriminant identity, the minimal polynomial, and the geometric factors. In the splitting case it reconstructs and saturates both linear graph ideals (saturation by `a` contracts from `k(sqrt(c))[t,a^-1,y]`) and checks their intersection reconstructs `(f)`. These graphs are geometrically prime by the primitive-degree-one argument.

```python
import sympy as sp
from alggeom.function_field_constants import algebraic_constant_field
from alggeom.ideals import PolynomialRing

x, y = sp.symbols("x y")
ring = PolynomialRing((x, y))
p = ring.ideal((x**7 + 1) ** 2 * y**2 - 2)
constants = algebraic_constant_field(p, max_candidates=1)
assert constants.verify(p)
assert len(constants.geometric_primes) == 2

regular = ring.ideal(y**2 - x**11 - 3)
assert algebraic_constant_field(regular).field == sp.QQ
assert algebraic_constant_field(regular).verify(regular)
```

**Generality boundary:** This is not an unconditional algorithm for `Frac(QQ[x]/P)` for arbitrary prime ideals. Other presentations retain a bounded candidate search; full relative constant fields for general higher extensions and nonprincipal primes remain outstanding. The verifier refuses to treat bounded search failures as a proof that there are no constants.

## Independent absolute primary-decomposition replay

`AbsolutePrimaryDecomposition.verify(original)` independently validates: (1) every component is primary by recomputing its associated primes, (2) each radical is geometrically prime via a separate exact criterion, (3) the intersection equals the extended original ideal, and (4) no component is redundant or has a duplicate associated prime. Embedded primary components are not removed merely because they are not minimal. This replay is independent of the candidate basis backend and from the absolute-decomposition constructor.

```python
from alggeom.geometric import absolute_primary_decomposition

f = y**2 - 2 * x**8
embedded = ring.ideal(x * f, y * f)
decomposition = absolute_primary_decomposition(embedded)
assert len(decomposition.components) == 3
assert decomposition.verify(embedded)
```

## Linear fibers on quotient localizations

Write each input equation as `f_i(a)*x+g_i(a)` on a basic open of an **arbitrary** parameter quotient `QQ[a]/I`, potentially with nilpotents, embedded components, or zero divisors. Split recursively on `f_i=0` and `f_i!=0`. On `f_i!=0`, the first equation is equivalent to `x+g_i/f_i=0`; every other equation reduces to the parameter determinant `f_i*g_j-f_j*g_i`. Branch on the full ideal generated by these determinants: where one is invertible, the fiber ideal is unit; where all vanish, it is monic linear. On `f_i=0`, branch on `g_i` and proceed to the next equation. This recursion terminates because it consumes an input equation or terminates at a leaf; `max_pieces` provides an explicit resource budget.

The verifier checks exact quotient-localization identities by saturation, validates the pivot/determinant witnesses, and proves the pieces disjoint and exhaustive on geometric parameter points by symbolic constructible-set operations. It never trusts a computed candidate Gröbner basis.

```python
from alggeom.localized_linear_cover import comprehensive_localized_linear_cover
from alggeom.parameter_localization import ParameterLocalization

a, b, v = sp.symbols("a b v")
parameter_ring = PolynomialRing((a, b))
base = ParameterLocalization(parameter_ring.ideal(a * b))
cover = comprehensive_localized_linear_cover((a * v + b, b * v + a), v, base)
assert cover.verify()
assert cover.specialize((0, 0)) == ()
assert cover.specialize((2, 0)) == (1,)
```

These are **pointwise** geometric-parameter covers, not scheme-theoretic flattenings of a nonreduced parameter algebra. The general higher-degree fiber Gröbner cover problem remains unresolved. The existing `comprehensive_prime_cover` remains available for supported nonlinear systems over prime parameter quotient function fields.
