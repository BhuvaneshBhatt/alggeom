# Radicals and components

Component decomposition separates different algebraic pieces of a system. A radical retains its vanishing equations while removing nilpotents. A primary decomposition also retains multiplicities and embedded components, which may be invisible in the reduced geometry.

```python
import sympy as sp
from functools import reduce
from alggeom.ideals import PolynomialRing
from alggeom.components import associated_primes, primary_decomposition, radical
from alggeom.schemes import AffineScheme

x, y = sp.symbols("x y")
S = PolynomialRing((x, y))
I = S.ideal(x * x, x * y)
components = primary_decomposition(I)
assert len(components) == 2
assert reduce(lambda a, b: a.intersection(b), components) == I
assert S.ideal(x).intersection(S.ideal(x * x, y)) == I
assert radical(I) == S.ideal(x)
assert all(
    any(p == expected for p in associated_primes(I)) for expected in (S.ideal(x), S.ideal(x, y))
)
assert AffineScheme(I).reduced().ideal == S.ideal(x)
```

Here the reduced support is the line x=0, but the origin has an embedded primary component. `minimal_primes(I)` gives only the reduced irreducible components; `associated_primes(I)` also includes embedded primes. Primary decompositions with embedded components are not unique. Code should check intersection, primary structure and associated primes instead of depending on a particular embedded generator list or component order.

All results are over the declared field. For example, `(x*x+1)` is prime over QQ and splits after extending constants to QQ(I). Use `Ideal.change_ring` or a scheme's `base_change` to request that extension. `is_prime` and `is_primary` decide the field-relative properties; neither treats the unit ideal as proper. The zero ideal of a polynomial ring is prime. The unit ideal has an empty component tuple, whose intersection is the unit ideal.

## Geometric components after extending constants

`geometric.absolute_primary_decomposition` also examines associated primes over `QQ` for algebraic constant extensions. When a Gröbner-basis polynomial on an associated prime factors geometrically, the implementation constructs a common number field, recomputes primary decomposition of the entire ideal over that field, and certifies each resulting associated prime using affine-linear or polynomial-graph presentations. It verifies the primary components' associated primes and their exact intersection. Embedded components are retained; `geometric_components` returns only minimal geometric components.

```python
from alggeom.geometric import absolute_primary_decomposition, geometric_components

x, y, z = sp.symbols("x y z")
S = PolynomialRing((x, y, z))
I = S.ideal(x**2 + y**2, x * z, y * z, z**2)
primary = absolute_primary_decomposition(I)
assert len(primary.components) == 3
assert len(geometric_components(I).components) == 2
```

A nonlinear prime may also be certified geometrically prime by an exact smooth rational point, and some nontrivial algebraic constant fields can be computed by saturated rational-function graphs. Both methods have explicit search limits. Arbitrary nonlinear prime ideals without such certificates remain unsupported; see the [constant-field guide](function_field_constants.md). The [prime parameter quotient guide](parameter_ideals.md) explains a separate coefficient-field construction for implicit nonlinear parameter varieties; primality of the parameter ideal over `QQ` is weaker than geometric primality.

## Algorithm and limits

The implementation follows the localization strategy of [Gianni, Trager and Zacharias, *Gröbner bases and primary decomposition of polynomial ideals* (1988)](https://doi.org/10.1016/S0747-7171(88)80040-3). A maximal independent coordinate set U gives a zero-dimensional generic algebra over K(U). Exact finite-algebra primary factors are contracted by clearing and saturating denominators. A product h of leading coefficients identifies the remaining closed locus. A certified exponent N with `h**N*(I:h**infinity) ⊆ I` gives the split `I = (I:h**infinity) ∩ (I+(h**N))`. Recursion handles the remaining locus, including components of smaller dimension.

Finite-algebra arithmetic belongs to algroots. In characteristic zero the kernel of its trace pairing is the nilradical. A separating linear form and irreducible factors of its characteristic polynomial separate primary local algebras, including those with several independent nilpotent directions. This does not assume that a nonreduced algebra is generated by one element.

`max_dimension` bounds each generic finite-algebra length; `max_nodes` bounds recursive loci; `max_exponent` bounds certified saturation stabilization; `max_separating_attempts` bounds the finite separator search. Exceeding an ideal limit raises `DecompositionLimitError`; a backend failure also raises. No partial tuple is presented as a complete decomposition. These limits do not impose a wall-clock or memory cap on a Groebner basis or factorization.

Supported coefficients are QQ, declared number fields, and their rational-function fields in characteristic zero. Generic coefficient parameters are invertible scalars; exceptional parameter specializations require separate calculations. Over supported finite fields, radicals are available in any dimension by Frobenius roots, and primary decomposition is available in dimension zero using Frobenius fixed subalgebras. Positive-dimensional primary decomposition in finite characteristic, radicals over imperfect coefficient fields, absolute decomposition over an unspecified algebraic closure, and automatic parameter stratification are outside this interface. See [finite fields](finite_fields.md). Scheme `irreducible_components()` returns reduced components, so use `primary_decomposition()` when embedded or nilpotent structure matters.
